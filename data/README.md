# Data Directory

This directory stores datasets used by the Flash Flood Prediction platform:
- `raw/`: Raw sensor timeseries, rainfall records, historical event catalogs.
- `processed/`: Cleansed, normalized, and engineered feature tables for AI models.
- `geojson/`: Watershed boundaries, river networks, evacuation zones, digital elevation model (DEM) vectors.
- `dem/`: Gridded elevation / terrain slope files for catchment modeling.
